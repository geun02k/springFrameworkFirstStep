조건 분기처리

th:if="조건"

th:if="조건" -> 조건 결과가 참일 경우, 조건절 태그 내 자식요소 출력

김하늘씨 입니다.

th:unless="조건"

th:unless="조건" -> 조건 결과가 거짓일 경우, 조건절 태그 내 자식요소 출력

영희씨가 아닙니다.

th:block

th:if, th:unless 처리를 위해 div 태그를 늘리고 싶지 않다면 th:block 태그 속성에 th:if, th:unless 추가가능.

th:block 태그는 렌더링 후 지워져 HTML 소스에 남지 않음.

김하늘입니다!

반복

th:each="요소저장용 변수 : ${서버에서 저장한 반복처리객체} 형식으로 반복처리 가능.

요소저장용변수는 반복처리중에만 유효.

Iterable 인터페이스를 구현한 클래스라면 th:each로 반복 처리 가능.

아이디 : 이름

[[${member.id}]] : [[${member.name}]]

반복 상태

th:each="요소저장용 변수, 상태변수, 서버에서 저장한 반복처리객체" 형식으로 반복 대상의 상태값 출력 가능.

상태변수를 선언해 반복상태를 유지한 상태변수 사용가능.

반복 상태 변수 목록

index : 현재의 인덱스 표시(0부터 시작)

count : 반복횟수표시(1부터 시작)

size : 반복 처리하는 객체의 사이즈 표시

current : 현재 반복 요소의 객체 표시

even : 현재 요소가 짝수 번째인지 여부 출력

odd : 현재 요소가 홀수 번째인지 여부 출력

first : 현재 요소가 첫번째 요소인지 여부 출력

last : 현재 요소가 마지막 요소인지 여부 출력

index -> [[${s.index}]], count -> [[${s.count}]], size -> [[${s.size}]], current -> [[${s.current}]], even -> [[${s.even}]], odd -> [[${s.odd}]], first -> [[${s.first}]], last -> [[${s.last}]], [[*{id}]] : [[*{name}]]


유틸리티 객체

타임리프에서는 자주 사용되는 클래스를 '#유틸리티객체' 상수로 정의.

#strings : 문자 관련 편의 기능

- 문자열의 길이와 대소문자 변환같은 String클래스와 유사한 메서드 제공

#numbers : 숫자 서식 지원

- 정수값 형식 변환 : #numbers.formatInteger

- 부동소수점 형식 변환 : #numbers.formatDecimal (쉼표 COMMA, 소수점 POINT 사용)

#bools : boolean 관련 기능

#dates : java.util.Date 서식 지원

- 날짜의 포맷 변환을 위해 현재 날짜 취득 or 연,월,일,요일 취득 메서드 제공

- format() : 날짜가 담긴 변수와 포맷 변환 문자열 지정

- year(),month(),day() : 날짜가 담긴 변수를 인수로 전달해 연,월,일 취득

- dayOfWeek() : 요일 나타내는 정수 취득

#objects : 객체 관련 기능

#arrays : 배열 관련 기능

#lists : List 관련 기능

#sets : Set 관련 기능

#maps : Map 관련 기능
