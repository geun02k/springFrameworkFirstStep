객체데이터 참조 방법

th:field="*{leftNum}"

th:field 속성 -> HTML로 표시되었을 때, id,name,value 속성 생성

*{ } -> 서버에서 데이터를 저장한 객체를 th:object에 설정 후 object 설정한 자식 요소에서 *{필드명} 형식으로 값 참조가능



에러표시

#fields.hasErrors()

- 에러 발생여부 판단

- 모든 필드의 에러를 받아 출력하므로 인수로 '*' 전달 (특정 필드 에러 받고 싶으면 인수로 필드명 전달)

- 에러 메시지를 배열로 반환하므로 th:each 속성을 이용해 표시.
